# Dopamine Vocab support site

このリポジトリは「ドーパミン英単語」専用のサポートサイトです。

- Bundle ID: `com.shirai.dopaminevocab`
- 公開先: `https://shirai-aka.github.io/dopamine-vocab-support/`
- 他アプリのページをこのリポジトリへ配置・公開しないでください。

公開前に次の検査を実行します。

```sh
sh scripts/validate_site.sh
```

検査は3ページすべてに正しいアプリ名があり、別アプリ名が混入していないこと、
プライバシーポリシーに現行の広告(Google AdMob のバナー・非パーソナライズ)と ATT の方針が記載されていることを確認します。
